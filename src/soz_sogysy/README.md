# Сөз Соғысы — слой отрисовки

Игра лежит в `templates/ageofwar2.html` (один самодостаточный файл).
Здесь — исходник её графики и сборщик, который вставляет его в игру.

```bash
node src/soz_sogysy/inject.js
```

Скрипт заменяет содержимое между маркерами `/*<<<WAR_RENDER_START>>>*/`
и `/*<<<WAR_RENDER_END>>>*/` внутри HTML. Файл остаётся одним HTML —
именно так его отдаёт GitHub Pages.

---

## Что было и что стало

**Было:** юниты, базы и турели — статичные PNG с чужих хостингов
(`ibb.co`, `tildacdn`), фоны эпох — тоже внешние картинки. Если хостинг
ляжет или у школы закрыт доступ — игра открывается пустой.

**Стало:** ни одного внешнего файла. Всё рисуется кодом:

| Что | Как сделано |
|---|---|
| Юниты | скелет из костей + процедурные циклы ходьбы/удара |
| Мамонт, катапульта, танк, мех | отдельные архетипы (`beast`, `machine`) |
| Фоны 5 эпох | шум Перлина: горы, вулканы, юрты, замки, трубы, неон-город |
| Земля | запечённая текстура с камнями и бликами |
| Базы | своя постройка на эпоху, с огнём/дымом/флагом и трещинами по мере урона |
| Турели, снаряды, взрывы | канвас, без картинок |
| Звук | уже был встроен в base64 — не трогали |

## Архитектура

`render.js` экспортирует `window.War`. Игровая логика к нему обращается
через несколько точек — сама логика не изменилась:

| Вызов | Когда |
|---|---|
| `War.init(canvas)` / `War.resize()` | при старте боя |
| `War.setEra(key)` | при смене эпохи |
| `War.makeUnit(u, eraKey)` | при рождении юнита — навешивает скелет |
| `War.attack(u)` / `War.hit(u)` / `War.die(u)` | удар / попадание / смерть |
| `War.boom(x, big)` | взрыв, попадание по базе, супер-удар |
| `War.draw(dt, state)` | каждый кадр; state — юниты, снаряды, турели, HP баз |
| `War.thumb(era, tier, w, h)` | портрет юнита для кнопки магазина |

Скелет — те же принципы, что в `src/tildik_kashu`: абсолютные углы
(90° = вниз, −90° = вверх, 0° = вперёд), кости плавно догоняют целевой
угол, поэтому переходы между ходьбой, боем и покоем получаются сами.

## Экипировка по эпохам

Таблица `GEAR` задаёт для каждой пары «эпоха + тир»: оружие (дубина,
праща, копьё, лук, меч, ружьё, граната, лазер), шлем/башлык/визор, щит,
броню и масштаб. Палитры — в `PAL`. Чтобы добавить эпоху, достаточно
дописать строку в `PAL`, `GEAR` и `THEME`.

## Что ещё изменено в игре

- **Дождь слов упрощён.** Раньше с неба падали буквы и слово собиралось
  по одной — это перекрывало поле и мешало бою. Теперь: одно слово, три
  эмодзи, одно касание. Авто-волны каждые 27 секунд убраны — дождь
  запускается только кнопкой.
- **Адаптив.** Телефон — базовая раскладка; от 760px ширины поле и
  колонка расширяются (планшет), от 1100px — ещё шире (ноутбук).
- Поле боя стало широкой полосой (3:2) вместо почти квадрата.
- Удалён мёртвый код: `unitSvg`, `turretSvg`, `projSvg`, внешние
  `IMG`/`SPRITES`.

## Отладка

В консоли браузера: `window.War` (движок) и `window.__AOW` (игра).

```js
__AOW.energy(500);        // дать энергии
__AOW.spawn(3,'p');       // выпустить юнита 4-го тира за себя
__AOW.era(4);             // прыгнуть в эпоху будущего
__AOW.step(1/60, 60);     // прогнать секунду симуляции вручную
__AOW.state;              // энергия, XP, HP баз, турели
```

Это удобно, когда вкладка в фоне и браузер замораживает анимацию.
