# Тілдік Қашу — платформер

Игра-побег на казахском: бег, прыжки, бой, а на пути — каменные ворота,
которые открываются только правильным переводом слова на английский.

**Собранный файл:** `templates/tildik_kashu.html` — один самодостаточный HTML,
никаких внешних файлов, шрифтов, картинок и звуков. Открывается по ссылке,
работает на телефоне, планшете и ноутбуке.

---

## Какой движок

**Свой, на чистом Canvas 2D.** Ни Phaser, ни Pixi, ни Unity.

Почему не готовый движок:
- `claude.md` этого репозитория прямо запрещает лишние библиотеки;
- Phaser — это +1 МБ и внешний CDN, а игра должна открываться одним файлом
  (в том числе там, где внешние запросы заблокированы);
- скелетная анимация и процедурные текстуры, которые здесь основа картинки,
  всё равно писались бы руками поверх любого движка;
- полный контроль над кадром: фиксированный шаг физики + свободная отрисовка.

Что пришлось написать самому (то, что обычно даёт движок):
игровой цикл с фиксированным шагом, ввод (клавиатура + мультитач),
тайловые коллизии, камеру, систему частиц, скелетную анимацию,
верле-физику ткани, синтез звука и генератор уровней.

| `05_skeleton.js` | кости, позы, верле-цепочки (плащ, волосы, хвост), отрисовка конечностей |

| `07_enemies.js` | четвероногая «тень», летун, босс — каждый со своим скелетом |

| `09_game.js` | цикл, экраны, HUD, словарные ворота |

Сборка:

```bash
node src/tildik_kashu/build.js
```

Создаёт два файла:
- `templates/tildik_kashu.html` — обычный HTML (GitHub Pages, локально, WebView);
- `src/tildik_kashu/dist_artifact.html` — тот же код без обёртки документа,
  для публикации как Artifact.

## Как устроена анимация

Никаких спрайт-листов. Персонаж — это дерево костей с **абсолютными углами**
(90° = вниз, −90° = вверх, 0° = вперёд), поэтому позы читаются прямо в коде:

```js
thighF: 90 + Math.sin(a) * sw,     // бедро качается вокруг вертикали
shinF:  90 + Math.sin(a) * sw + 22 + Math.max(0, Math.sin(a + 1.1)) * 52,
```

Кости не переключаются между кадрами, а **плавно догоняют целевой угол**
(`angDamp`), поэтому переходы между бегом, прыжком и ударом получаются сами —
отдельных «переходных» анимаций нет.

Поверх скелета — вторичная анимация на верле-цепочках: плащ, три пряди волос,
хвост зверя. Они не анимированы вручную, а реагируют на скорость, прыжок и ветер.

Конечности рисуются конусными капсулами с градиентом поперёк кости плюс
кружок в суставе — без сустава конечности «расползаются» на изгибе.

## Как устроены текстуры

Всё рисуется кодом при загрузке и **запекается** в оффскрин-холсты:
шум Перлина → базовый тон земли, поверх — камушки, корешки, дёрн с травинками.
Каждого тайла по 3 варианта, вариант выбирается хешем координат — поэтому
поверхность не повторяется рисунком.

Тема уровня тонирует текстуры один раз при загрузке
(`Tex.tintAll`, режим `multiply`), поэтому три уровня выглядят тремя мирами
при одном наборе исходных текстур.

## Уровни

Генерируются из готовых кусков (`flat`, `gap`, `stairs`, `platforms`, `spikes`,
`crates`, `tower`, `moving`, `gate`) детерминированным ГСЧ по `seed` из `LEVELS`.
Один и тот же seed всегда даёт один и тот же уровень — можно править баланс,
не переделывая карту руками.

Правила, добытые тестами:
- первые 13 тайлов и первый кусок — всегда ровная земля;
- враги не появляются в первых 26 тайлах;
- точка возрождения запоминается только там, где твердь продолжается
  по обе стороны — иначе игрок возрождается на краю пропасти и падает снова.

## Обучающий слой

Каждый уровень — свой набор из 10 слов (`WORDS` в `09_game.js`):
природа → школа → глаголы. Ворота показывают казахское слово и три варианта
на английском. Правильный ответ ломает дверь и даёт +100. После второй ошибки
дверь открывается всё равно, но без очков — ребёнок не должен застрять.
В конце — список всех слов, которые он открыл.

## Отладка

В консоли браузера доступен `window.__TK` — `{ Game, Input, World, FX, Cam, Sfx, Tex, LEVELS, WORDS }`.
Можно шагать симуляцию вручную (полезно, когда вкладка в фоне и rAF заморожен):

```js
__TK.Input.keys.ArrowRight = true;
for (let i = 0; i < 120; i++) __TK.Game.step(1/60);
__TK.Game.draw();
```
