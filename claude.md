# CLAUDE.md

## О проекте

Этот репозиторий содержит HTML5-игры, интерактивные презентации и образовательные демонстрации.

Основной стек:

- HTML5
- CSS3
- Vanilla JavaScript
Это не обязательно - просто так привычно, можно писать на чем угодно

Не использовать сторонние библиотеки если это не позволит пользователю использовать ту или иную игру или тест с браузера по ссылке, от него не должно ттребоваться ничего более

---

## Цель

Создавать красивые, современные, быстрые и удобные HTML-приложения.

---

## Стиль разработки

Всегда:

- писать чистый код;
- разбивать большой код на логические части;
- использовать понятные имена функций;
- избегать дублирования;
- оставлять код легко поддерживаемым.

---

## Дизайн

- Токены стиля (палитра, радиусы, тени) — из `templates/arcade.html`.
- Mobile first (375 px), адаптивно для планшетов и макбуков.

## Перед завершением работы

Открыть страницу по ссылке GitHub Pages на ширине 375 px: нет горизонтального скролла, всё нажимаемое не меньше 44 px, в консоли нет ошибок.
