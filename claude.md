# CLAUDE.md

## О проекте

Этот репозиторий содержит HTML5-игры, интерактивные презентации и образовательные демонстрации.

Основной стек:

- HTML5
- CSS3
- Vanilla JavaScript

Не использовать сторонние библиотеки без необходимости.

---

## Цель

Создавать красивые, современные, быстрые и удобные HTML-приложения.

---

## Стиль разработки

Всегда:

- писать чистый код;
- разбивать большой код на логические части;
- использовать понятные имена функций;
- избегать дублирования;
- оставлять код легко поддерживаемым.

---

## Дизайн

По умолчанию использовать:

- современный минимализм;
- плавные анимации;
- красивые тени;
- аккуратные кнопки;
- адаптивность.

---

## Перед завершением работы

Всегда:

- проверить HTML;
- проверить CSS;
- проверить JavaScript;
- убедиться, что нет ошибок.

---

## Git

Никогда не выполнять git commit или git push автоматически.

Сначала показать изменения.

Выполнять commit и push только после моего подтверждения.
