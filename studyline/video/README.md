# Видео-разборы НИШ — обучающая линия StudyLine

Вертикальные ролики 1080×1920, интерфейс и озвучка казахские.
Каждый ролик разбирает **одну задачу из банка НИШ** и обязательно объясняет,
**почему** типичный ход мысли неверен — иначе это не обучение, а показ ответа.

Собирается в **HyperFrames** (HTML → MP4), озвучка — **kie.ai**
(`google/gemini-3-1-flash-tts`, голос Kore).

| Папка | Тема | Длина | Мастер |

| `nish_03_tolyq_test/` | Целый мини-тест НИШ: 6 вопросов, 6 предметов | сценарий готов | **озвучки нет** — на kie.ai закончились кредиты (`402 Credits insufficient`) |

Обложка каждого ролика — `out/*_cover.jpg`, снята с 1,2 с: этот кадр обязан
работать как превью в ленте.

## Как собрать следующий ролик

1. Взять задачу из `../../../StudyLine/StudyLine_БАНК_20_ЗАДАЧ_НИШ.md` (20 штук).
2. Написать `vo_kz.txt` — **одна реплика на строку**, каждая строка = одна сцена.
   Драматургия фиксированная и менять её не надо:
   `хук → условие → типичная ошибка → шаг 1 → шаг 2 → ответ → почему именно так → CTA`.
   Предпоследняя сцена — самая важная: без неё ребёнок запомнит ответ, а не правило.
3. Озвучить:
   ```bash
   python3 ~/.claude/tools/kie/kie.py tts --lines vo_kz.txt --voice Kore \
     --style "Vocal Smile" --pace Natural \
     --context "Учебное видео на казахском для детей 10-12 лет. Спокойный уверенный учитель." \
     --out vo --name vo
   cp vo/*.wav assets/vo/
   ```
4. Замерить реальные длительности — тайминги сцен берутся из них, а не на глаз:
   ```bash
   for f in vo/*.wav; do printf "%s %s\n" "$f" \
     "$(ffprobe -v error -show_entries format=duration -of csv=p=0 "$f")"; done
   ```
5. Скопировать `index.html` соседнего ролика, поменять сцены и проставить
   `data-start` / `data-duration` нарастающим итогом по замеренным длинам.
6. `npx hyperframes check` — должно быть **0 errors** и все контрастные проверки WCAG AA.
7. `npx hyperframes snapshot --at ...` и посмотреть контактный лист глазами.
8. `npx hyperframes render --fps 30 --quality high --workers 6`.
9. Кроп 4:5 и обложку — командами из `build.sh` соседнего ролика.

## Грабли, каждая стоила прогона

| Грабля | Что делать |
|---|---|
| `media_missing_id` — аудио **молчит в рендере** | у каждого `<audio>` обязан быть `id`, иначе рендер его не найдёт |
| `duplicate_audio_track` | соседние реплики не должны стыковаться встык: `data-duration` берём на 0,06 с короче реального файла |
| Контраст ниже WCAG AA | белый текст на `--green` (#87BE4B) даёт 2,2:1. Плашки с белым текстом красим в `--green-t` (#456F1B) или #A8791E |
| Текст вылезает из плашки | абсолютный `bottom:-62px` внутри столбца ловится проверкой `text_box_overflow` — подпись держим внутри бокса |
| Числа в озвучке | в `vo_kz.txt` пишем **словами по-казахски** («жиырма төрт»), на экране остаётся `24` |
| Латиница в озвучке | `StudyLine` читается нормально, а термины вроде «-ing» — нет, их пишем кириллицей |

## Что осознанно не сделано

- **Музыки и SFX нет.** Это обучающий ролик, а не реклама: фоновая музыка под
  объяснение математики мешает считать. Если понадобится — держать её на −18 dB
  относительно голоса, не громче.
- **Караоке-субтитров нет** — kie.ai не отдаёт word-timings. Вместо них ключевая
  фраза вжигается в кадр на всю сцену, тайминги берутся из `ffprobe` реальных WAV.
- **Третий ролик не озвучен** — кончился баланс kie.ai. Сценарий, тайминги
  и структура готовы, после пополнения нужен один прогон TTS и один рендер.
