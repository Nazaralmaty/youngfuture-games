# 100 деңгей — прототип

Один файл: `index.html`. Открывается двойным кликом или по ссылке, без сборки и CDN.
Прогресс — `localStorage` (ключ `sl100_v1`). Интерфейс казахский.

## Что внутри

| Экран | Что делает |
|---|---|
| Басты | копия главного экрана приложения. Кликабельна одна карточка — «Практикалық тесттер» |
| Тест | 6 вопросов, по одному на предмет: математика, логика, қазақ, орыс, ағылшын, жаратылыстану |
| Нәтиже | счёт, XP, новое звание. Уровень открывается при **≥4 из 6** (константа `PASS`) |
| Карта | 20 уровней первой эпохи, целиком в один экран 9:16. Внизу — кнопка на следующий уровень и переключатель 5 эпох |
| Карточка героя | открытая и закрытая версии, шторкой снизу |

**Одно имя на уровень.** Уровень 3 — это Баян батыр: так подписан узел на карте,
так называется карточка, так объявляется награда после теста. Отдельной лестницы
званий (`StudyLine_100_АТАҚТАР_RU.md`) здесь нет — это другая, XP-механика,
и смешивать их на одном узле оказалось нечитаемо.

## Как устроена карта

Пять полос-регионов, каждая = ряд из 4 узлов + своя полоса мира над ним
(`.band` = `.rrow` + `.gap`). В полосе мира стоят юрта, Алатау, река, костёр,
курган с балбалом — inline SVG в объекте `ART`, раскладка в `GAP`. Полоса
существует именно для того, чтобы декору было куда встать: узлы занимают всю
ширину, и без неё мир налезает на уровни. Туман накрывает ряд и полосу разом.

## Туман войны

20 уровней разбиты на 5 аймақ по 4 (`REGIONS`). Аймақ открывается, когда пройден
последний уровень предыдущего (`regionOpen`). Под туманом не видно ни имени героя,
ни звания, ни характеристик — тап по туману открывает **закрытую** карточку
с подписью «Ашылуға N деңгей қалды».

## Отладочные ссылки

Работают и для дизайнера — состояние подставляется в URL:

- `index.html?done=7&go=map` — прогресс 7, сразу карта
- `index.html?hero=15&done=7` — закрытая карточка героя 15
- `index.html?hero=6&done=7` — открытая карточка
- `index.html?go=result&right=5` — экран результата
- `index.html?test=1` — самопроверка данных и логики, результат в консоли

## Как добавить остальные 80 уровней

1. Дописать в `HEROES` объекты того же вида: `n` имя, `y` годы, `p` регион·ру,
   `hue` оттенок медальона 0–360, `h` фраза-крючок, `s` `[батылдық, ақыл, әділдік]`,
   `d` описание **400–600 знаков** (проверяется в `?test=1`).
   Первое слово `n` идёт подписью узла — оно должно быть уникальным.
2. Задать эпохе свои 5 названий регионов (`REGIONS`) и 5 наборов декора (`GAP`).
3. В `BIOMES` поставить эпохе `open:true`.
4. Карта строится из тех же 20 узлов, менять её код не нужно.

## Что заменит дизайнер

- 3D-иллюстрации главного экрана — сейчас эмодзи (`🦉 📚 🏆 📋 📘`).
- Портреты героев — сейчас SVG-медальон с орнаментом и первой буквой имени
  (функция `medallion`). Формат замены: круг 96×96, закрытая версия — силуэт.
