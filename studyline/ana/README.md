# Ана кабинеті — рабочий срез «недельного уровня мамы»

Один файл: `index.html`. Открывается по ссылке, без сборки и CDN.
`localStorage` (`sl_ana_v1`), интерфейс казахский.
Полная раскадровка всех четырёх разделов — `StudyLine/ana_kabineti_concept_v6.html`.

## Зачем именно этот срез

В акте работ 1 июля — 9 августа главный продуктовый вывод звучал так:

> Сейчас кабинет = отчёт об успеваемости ребёнка (источник тревоги, невозможно
> расшарить). Недельный уровень мамы с призом — первая ценность, которую хочется
> показать подруге. Отсюда начинается и retention, и реферал.

Отсюда единственное принципиальное решение этого экрана: **первым идёт уровень
мамы, а не оценки ребёнка.** Оценки — вторым экраном и без тревожных
формулировок. Это проверяется автотестом: если однажды блок ребёнка окажется
выше блока мамы, проверка упадёт.

## Что работает

| Механика | Как сделано |
|---|---|
| Уровень мамы | 300 XP на уровень, 10 названий от «Жаңа ана» до «Жұлдыз ана». **Уровень никогда не падает** — только растёт. Это написано прямо на экране и проверено тестом |
| Задание недели | Шесть заданий, все про «мама и ребёнок вместе», ни одно — про контроль оценок |
| Фото | Настоящий выбор с телефона, сжатие до 720 px / JPEG 0.72 (40–80 КБ) |
| Приз | Открывается за выполненное задание, лесенка из шести |
| Семейная галерея | Фото видны **только своей семье**: ни в какой ленте, ни в каком рейтинге. Незаработанные недели — закрытые ячейки |
| Карточка для шеринга | Генерируется на canvas 1080×1350 и сохраняется как PNG |
| Отчёт по ребёнку | Отдельным экраном: XP по дням, слабый предмет назван. Места в классе нет |

## Карточка для подруги — где именно начинается реферал

Кнопка «Деңгейімді көрсету» рисует картинку 1080×1350 и сохраняет её.
На картинке: корона, номер уровня, название уровня, сколько недельных заданий
выполнено, полоса прогресса и `studyline.kz`.

**Чего на картинке нет и не будет: имени ребёнка, класса, оценок, его фото.**
Мама делится своим достижением, а не отчётом о ребёнке — иначе делиться
никто не станет. На это стоит отдельная проверка в `?test=1`.

## Почему в отчёте нет места в классе

«12-е место из 28» даёт тревогу, но не говорит, что делать. Вместо этого
названо, какой предмет слабее остальных — это уже действие. Проверка следит,
чтобы номер места не появился в отчёте снова.

## Режимы

| Ссылка | Что показывает |
|---|---|
| `index.html` | 7-й уровень, 260/300 XP, 4-я неделя — как в концепте v6 |
| `index.html?empty=1` | первая неделя, 0 XP: как выглядит кабинет у новой семьи |
| `index.html?lvl=2&week=2` | ранний уровень |
| `index.html?test=1` | самопроверка, 21 проверка в консоли |

## Что осознанно не сделано

- **Бэкенда нет.** XP ребёнка (`KID_WEEK`) захардкожены — это данные сервера.
  Фото лежат в `localStorage` как data-URL; при переполнении уровень и прогресс
  сохраняются, а старые фото сбрасываются с честным тостом.
- **Разделы «Жаңалықтар», «Мектептер», «Жол картасы», настройки** — есть
  в концепте v6, здесь не дублируются. Тут только та часть, ради которой
  переделывается кабинет.
- **Web Share API не используется** — на десктопе и части браузеров он
  отсутствует или требует файла. Сохранение PNG работает везде одинаково.
