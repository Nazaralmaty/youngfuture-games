# Квиз 1English — копия 1eng.kz/quiznew

Ссылка: https://nazaralmaty.github.io/youngfuture-games/1english-quiz/

Страница — копия квиза с 1eng.kz/quiznew: тот же код Тильды, те же картинки, тексты, цвета и кнопки. Отличия:

1. Первым идёт вопрос «Жасыңыз нешеде?». Ответ «18 жасқа дейін» или «50 жастан жоғары» закрывает квиз экраном «Рақмет! Бірақ сіз бізге жарамайсыз»: дальше пройти нельзя, ничего не отправляется, Lead в Pixel не уходит. Телефон это запоминает: после перезагрузки экран тот же.
2. Одна заявка на человека. С того же телефона после отправки вместо квиза открывается «Өтінішіңіз бізде бар». Номер, который уже есть в таблице, второй раз не записывается (с любого устройства), человек видит тот же экран, Lead не уходит. Для своих тестов: открыть ссылку с `?reset=1` в конце, телефон «забудет» прошлую заявку.
3. После отправки открывается `thanks.html`: «Рақмет! Өтінішіңіз қабылданды» и кнопка в Instagram @1eng.kz.
4. Заявка уходит в Google Таблицу через Apps Script, а не в сервисы форм Тильды: с github.io Тильда заявки не принимает.

Сейчас включён тест-режим: таблица не подключена, на странице «Рақмет» внизу красным написано «Тест-режим».

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | квиз |
| `thanks.html` | страница «Рақмет» с кнопкой в Instagram |
| `apps-script.gs` | код для Google Таблицы, принимает заявки |
| `tilda-block.html` | только экран «жарамайсыз» по возрасту, для T123 на странице в Тильде |
| `check.mjs` | автопроверка в Chrome |

## Подключить таблицу

1. Создать Google Таблицу → Расширения → Apps Script → стереть всё в `Code.gs`, вставить `apps-script.gs`, сохранить.
2. Выбрать функцию `testPost` → Выполнить → разрешить доступ. На листе «Лиды» появится тестовая строка, её можно удалить.
3. Начать развёртывание → Новое развёртывание → «Веб-приложение», запуск от имени «я», доступ «все». Скопировать ссылку `https://script.google.com/macros/s/ДЛИННЫЙ_КОД/exec`.
4. В `index.html` найти `var SHEET_URL = '';` и вставить ссылку между кавычек.

Колонки: дата, имя, телефон, возраст, цель, уровень, сколько учит, готовность, utm-метки, fbclid, страница. Если код в Apps Script поменялся, нужно «Управление развёртываниями → изменить → новая версия».

## Если квиз остаётся на 1eng.kz

Как добавить экран «жарамайсыз» в квиз прямо в Тильде (проверка номера на повтор там не работает: заявки идут в CRM Тильды, не в нашу таблицу):

1. В квизе на первом месте добавить вопрос «Жасыңыз нешеде?» с ответами ровно такими: `18 жасқа дейін`, `18–25 жас`, `26–35 жас`, `36–50 жас`, `50 жастан жоғары`.
2. На ту же страницу добавить блок T123 и вставить в него `tilda-block.html`.
3. Thank-you: в настройках формы квиза → «После успешной отправки» → ссылка на страницу «Рақмет» (можно на `https://nazaralmaty.github.io/youngfuture-games/1english-quiz/thanks.html`).

## Проверка

```sh
node check.mjs
```

Проходит квиз в Chrome на ширине 375 px: оба «неверных» возраста показывают «жарамайсыз», квиз дальше не идёт и после перезагрузки тоже, ничего не шлётся; полный путь отправляет все пять ответов, имя и телефон одним запросом в таблицу и ни одного в Тильду, потом открывается `thanks.html` со ссылкой на Instagram; повторный заход с того же устройства показывает «Өтінішіңіз бізде бар»; номер, который таблица уже знает, не даёт ни строки, ни Lead. Если отправка упала, человек остаётся на форме, видит ошибку, Lead не уходит. В конце `apps-script.gs` прогоняется на ненастоящей таблице: тот же номер второй раз отклоняется.
