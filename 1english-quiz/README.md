# Квиз 1English — заявки в Google Таблицу

Пробная версия: https://nazaralmaty.github.io/youngfuture-games/1english-quiz/

Сейчас квиз в тест-режиме: таблица не подключена, заявки никуда не уходят. После отправки на экране написано «Тест-режим».

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | квиз целиком, его открывает GitHub Pages |
| `tilda-block.html` | тот же квиз без обёртки, вставляется в Тильду |
| `apps-script.gs` | код для Google Таблицы, принимает заявки |
| `check.mjs` | автопроверка: возраст, маска телефона, отправка, Pixel |

## 1. Таблица и Apps Script (10 минут)

1. Создать Google Таблицу, например «1English — лиды квиза».
2. В таблице: Расширения → Apps Script.
3. Стереть всё в `Code.gs`, вставить содержимое `apps-script.gs`, сохранить.
4. Проверка без сайта: сверху выбрать функцию `testPost` → Выполнить → разрешить доступ к таблице. В таблице появится лист «Лиды» с тестовой строкой. Её можно удалить.
5. Начать развёртывание → Новое развёртывание → тип «Веб-приложение».
   - Запуск от имени: **я**
   - У кого есть доступ: **все**
6. Скопировать ссылку вида `https://script.google.com/macros/s/ДЛИННЫЙ_КОД/exec`.

Если позже меняется код в Apps Script, нужно сделать «Управление развёртываниями → изменить → новая версия». Иначе работает старый код.

## 2. Подключить таблицу к квизу

В `index.html` найти строку

```js
var SHEET_URL = '';
```

и вставить ссылку между кавычек. Потом в Терминале из этой папки запустить `./build-tilda.sh`, он обновит `tilda-block.html`.

## 3. Перенос в Тильду

1. Новая страница → блок **T123** (HTML-код) из раздела «Другое».
2. Вставить всё содержимое `tilda-block.html` → Сохранить → Опубликовать.
3. Квиз занимает весь экран. Шапку и подвал Тильды на этой странице лучше отключить.

Пиксель: если Meta Pixel уже подключён в настройках сайта Тильды, квиз повторно его не запускает и использует тот же. Если нет, запускает сам (ID `2168758820343543`).

## Что куда уходит

- Возраст до 18 или старше 50: экран «Рақмет!», в таблицу ничего не пишется, Lead не отправляется. Apps Script отдельно отклоняет такие заявки, даже если кто-то пошлёт их в обход сайта.
- Возраст 18–50: после имени и телефона строка в листе «Лиды» — дата, имя, телефон, четыре ответа, utm-метки из ссылки рекламы, fbclid, адрес страницы.
- `Lead` в Pixel уходит только после того, как таблица ответила «записано». Если отправка не прошла, человек видит «Жіберілмеді» и кнопку «Қайта жіберу», Lead не уходит.
- Телефон проверяется: +7 и 10 цифр. В таблице хранится как текст `+77011234567`.

## Проверка

```sh
node check.mjs
```

Проходит квиз в Chrome: отсев по возрасту, маска телефона, все ответы в заявке, один Lead после успеха, ошибка отправки без Lead, кнопки не меньше 44 px.
