# Квиз 1English — копия 1eng.kz/quiznew

Ссылка: https://nazaralmaty.github.io/youngfuture-games/1english-quiz/

Страница — копия квиза с 1eng.kz/quiznew: тот же код Тильды, те же картинки, тексты, цвета и кнопки. Отличий три:

1. Первым идёт вопрос «Жасыңыз нешеде?». Ответ «18 жасқа дейін» или «50 жастан жоғары» закрывает сайт: ничего не отправляется, Lead в Pixel не уходит. Закрыть вкладку браузер даёт не всегда, поэтому там, где не даёт, вместо сайта открывается пустая страница, и кнопка «Назад» обратно не ведёт.
2. После отправки открывается `thanks.html`: «Рақмет! Өтінішіңіз қабылданды» и кнопка в Instagram @1eng.kz.
3. Заявка уходит в Google Таблицу через Apps Script, а не в сервисы форм Тильды: с github.io Тильда заявки не принимает.

Сейчас включён тест-режим: таблица не подключена, на странице «Рақмет» внизу красным написано «Тест-режим».

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | квиз |
| `thanks.html` | страница «Рақмет» с кнопкой в Instagram |
| `apps-script.gs` | код для Google Таблицы, принимает заявки |
| `tilda-block.html` | только «закрытие сайта» по возрасту, для T123 на странице в Тильде |
| `check.mjs` | автопроверка в Chrome |

## Подключить таблицу

1. Создать Google Таблицу → Расширения → Apps Script → стереть всё в `Code.gs`, вставить `apps-script.gs`, сохранить.
2. Выбрать функцию `testPost` → Выполнить → разрешить доступ. На листе «Лиды» появится тестовая строка, её можно удалить.
3. Начать развёртывание → Новое развёртывание → «Веб-приложение», запуск от имени «я», доступ «все». Скопировать ссылку `https://script.google.com/macros/s/ДЛИННЫЙ_КОД/exec`.
4. В `index.html` найти `var SHEET_URL = '';` и вставить ссылку между кавычек.

Колонки: дата, имя, телефон, возраст, цель, уровень, сколько учит, готовность, utm-метки, fbclid, страница. Если код в Apps Script поменялся, нужно «Управление развёртываниями → изменить → новая версия».

## Если квиз остаётся на 1eng.kz

Как добавить «закрытие сайта» в квиз прямо в Тильде:

1. В квизе на первом месте добавить вопрос «Жасыңыз нешеде?» с ответами ровно такими: `18 жасқа дейін`, `18–25 жас`, `26–35 жас`, `36–50 жас`, `50 жастан жоғары`.
2. На ту же страницу добавить блок T123 и вставить в него `tilda-block.html`.
3. Thank-you: в настройках формы квиза → «После успешной отправки» → ссылка на страницу «Рақмет» (можно на `https://nazaralmaty.github.io/youngfuture-games/1english-quiz/thanks.html`).

## Проверка

```sh
node check.mjs
```

Проходит квиз в Chrome на ширине 375 px: оба «неверных» возраста закрывают страницу и ничего не шлют; полный путь отправляет все пять ответов, имя и телефон одним запросом в таблицу и ни одного в Тильду; потом открывается `thanks.html` со ссылкой на Instagram. Если отправка упала, человек остаётся на форме, видит ошибку, Lead не уходит.
